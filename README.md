## 主要功能

- 核心与显存频率偏移
- 功耗上限与 Boost Lock
- Blackwell NVVDD/MSVDD 电压轨与 Voltage Boost
- Crossbar 偏移
- RTX 50 V/F 127 点曲线编辑
- V/F 右键框选、多点整体平移、键盘微调、区域修改与拉平
- Power Monitor、Power Topology 与降频原因遥测
- 中英文界面
- 系统托盘后台运行
- GPU/VBIOS 绑定配置档
- 一键复位全部调校项目并执行 GET 回读

## 写入与异常处理

- 程序启动后只读取当前驱动状态，不会自动应用上一次的超频配置。
- 常规调校在应用前显示确认；一键复位直接执行。
- 每次写入前保存所需接口的完整快照，写入后使用 GET 回读验证。
- 回读不一致或中途失败时，程序尝试按逆序恢复写入前状态。
- 某个电压、V/F、Crossbar、功耗或调校接口不可用时，对应模块会停用或留空，其他可用遥测继续刷新。
- 一键复位需要所有相关接口均可读取；任何必需接口缺失都会在第一个 SET 之前整体取消。

设备掉线、驱动崩溃或系统重启时，软件级回滚不能保证一定成功。

## 运行

1. 下载 `NV Voltelle.exe`。
2. 双击运行并接受 UAC 管理员权限请求。
3. 确认程序正确识别 GPU、驱动、VBIOS 和各接口状态。
4. 小步调整参数，并自行完成负载稳定性测试。

命令行参数：

- `--read-only`：只读取，不发送硬件写入。
- `--start-in-tray`：启动后进入系统托盘。
