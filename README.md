## 主要功能

- NVIDIA GPU 核心、显存频率偏移、功耗上限、电压范围与时钟调校。
- NVVDD / MSVDD OCP 电流阈值独立控制，支持新旧驱动布局检测和写后回读；分别不超过默认值的 125% / 100%，且受驱动上限限制。
- 笔记本 GPU 自动禁用整板功耗上限调节；OCP 和其他选项继续按实际驱动能力独立检测。
- NVVDD / MSVDD 电压范围、Crossbar、SYS、Video、GPU 时钟范围与 V/F 曲线编辑。
- 多风扇控制、实时遥测、可选扩展时钟读数，以及可置顶和复制的设置摘要。
- GPU / VBIOS 绑定配置档、全局配置快捷键、一键复位与延迟启动应用；分项失败不阻断其他项目。
- 中文 / English、黑白主题、50%–200% 连续缩放、总览卡片显隐与可选采样间隔。
- 系统托盘后台运行，收进托盘后暂停动画和遥测。
- 显卡高性能模式、旧版本数据清理和 GitHub 更新检查。
- 配置与缓存按软件版本绑定；版本不匹配时自动重建。

## 使用方法

1. 从 [Releases](https://github.com/YuanChu0512/NV-Voltelle/releases) 下载 `NV Voltelle x.x.x Portable.exe`，直接运行并通过 Windows 管理员权限确认。
2. 修改所需项目后应用并检查回读结果；不支持的选项会单独置灰。建议一次只调整一个变量。
3. 在“配置档”中保存、应用配置，也可为已保存配置设置如 `Ctrl+Alt+1` 的快捷键；快捷键应用仍需确认。
4. 左下角“开机自启”只控制登录后启动软件；如需自动应用参数，在“配置档”开启延迟应用并选择启动预设。手动启动不会自动应用预设。
5. 在“设置”拖动缩放条或输入百分比，调整采样间隔；扩展时钟默认关闭，其名称映射仍属实验性。
6. 右键总览卡片可隐藏，在“设置”恢复；页头“设置摘要”可查看并复制当前读数。
7. 收到系统托盘后暂停动画与遥测；重新显示窗口时恢复采样。
8. 升级到不同版本会重建旧配置和界面设置，并清理旧自启任务；请提前记录所需参数，升级后重新保存配置及设置自启。

当前验证范围：GeForce RTX 5070 Ti 及以上的桌面端和移动端型号；其他型号未验证，可用功能以实际驱动检测为准。
